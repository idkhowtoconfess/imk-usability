# WEBSITE MATERI USABILITY

## 1. Deskripsi

Website ini merupakan media pembelajaran berbasis web yang dibuat untuk menyajikan materi mengenai **Usability** pada mata kuliah **Interaksi Manusia dan Komputer**.

Website dirancang sebagai alternatif penyampaian materi yang lebih interaktif dibandingkan dengan metode presentasi konvensional. Materi disusun dalam beberapa bagian yang dapat diakses melalui antarmuka website sehingga pengguna dapat mempelajari konsep usability secara lebih terstruktur.

## 2. Tujuan

Pembuatan website ini bertujuan untuk:

1. Menjelaskan konsep dasar usability dalam Interaksi Manusia dan Komputer.
2. Menyajikan materi pembelajaran dalam bentuk website yang interaktif.
3. Menerapkan prinsip-prinsip usability pada sebuah antarmuka pengguna.
4. Memberikan pengalaman pembelajaran yang lebih menarik dan mudah dipahami.

## 3. Teknologi yang Digunakan

Website ini dikembangkan menggunakan teknologi berikut:

* HTML5 sebagai struktur utama halaman.
* CSS3 sebagai pengatur tampilan, layout, dan desain antarmuka.
* JavaScript sebagai pendukung fungsi dan interaksi pada website.
* GitHub Pages sebagai layanan hosting untuk mempublikasikan website.

## 4. Struktur File

Struktur utama repository website adalah sebagai berikut:

```text
website-usability/
├── index.html
├── style.css
├── script.js
└── assets/
    └── ...
```

## 5. Deployment

Website dipublikasikan menggunakan GitHub Pages. Layanan ini digunakan untuk melakukan hosting terhadap website berbasis HTML, CSS, dan JavaScript secara gratis.

Setelah repository dikonfigurasi menggunakan GitHub Pages, website dapat diakses melalui alamat:

```text
https://username.github.io/nama-repository/
```

## 6. Keterangan

Website ini dibuat sebagai bagian dari tugas mata kuliah Interaksi Manusia dan Komputer dengan materi pembahasan mengenai Usability.
